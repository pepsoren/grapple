# grapple brand

**Logo (round 9, "good enough for now", 2026-10-18):** a jagged geometric grappling hook with a fine cord
threaded through its eye, white on tether's green, in tether's app-icon format (white mark on one accent
colour, tether's tile corner = 1/3 of the tile). The name is always lowercase: **grapple**, like **tether**.

| File | Use |
| --- | --- |
| `grapple-icon.svg` | App icon: green tile, white mark, hard dark-green edge |
| `grapple-icon-flat.svg` | Same without the edge |
| `grapple-mark-mono.svg` | Mark only, `currentColor` (light/dark backgrounds) |
| `png/grapple-<size>.png` | 16 to 1024 px renders of `grapple-icon.svg` |

Colours: tile `#4ade80` (tether's green accent swatch), mark `#ffffff`, edge `#1d7a44`.
The concept rounds that led here are `logo-concepts.html`, `logo-02.html` … `logo-09.html` (history only).
